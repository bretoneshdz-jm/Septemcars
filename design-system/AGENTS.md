# AGENTS.md — personal design system (v0.1.1)

> **AI entry guide.** Read this before using any component or token from
> this design-system package.

## What this is

This package is the exported design system for **personal**, generated by the
DS Foundations Engine. It contains typed React components and a CSS token
file (`tokens.css`).

## Golden rules

1. **Prefer these components.** Don't invent new UI primitives — pick from
   the component index below.
2. **Reference tokens as `var(--ds-*)`.** Never hard-code hex values.
   Import `tokens.css` once at your app root.
3. **Respect token families:**
   - `surface.*` → background fills
   - `content.*` / `text.*` → text / foreground colour
   - `border.*` → stroke / border colours
   - `icon.*` → glyph / SVG fill colour
4. **Don't invent styles.** Only override tokens; don't write new CSS that
   contradicts the design system.
5. **Read the component `.md` before instantiating.** Each doc lists the
   available props, when to use, and dos/don'ts.

## Relations map (`design-system.json`)

- **Before styling a part of a component, look up its token in `design-system.json` → `components[].tokenUsage`; do not infer it.**
  Each entry names the part, the property and, when it applies, the
  variant or state (`when`).
- **Before creating a new component, check `embeds` and `usedBy`: it may already exist as a composition.**
- Token ids in `tokens` and `tokenUsage` are canonical: semantic colours
  without the `semanticColors.` prefix, colour primitives as
  `colors.<hue>.<step>` (no `.light` / `.dark` segment). `tokensUsed`
  keeps the refs as written in the component.
- Internal (non-public) sub-components have no relation fields of their own:
  their token usage appears under the parent component's `tokenUsage`,
  with the internal part names.

## Agent skills

This repo ships two agent skills in `.claude/skills/` and `.agents/skills/` (Claude Code, Codex, Cursor):

- **`personal-build-ui`**: use it when creating or changing UI.
- **`personal-audit`**: audits how the code uses the design system. Run it by hand with `node .claude/skills/personal-audit/scripts/audit.mjs --json`.

## Importing components

```tsx
// Once in your app root:
import "@personal/design-system/tokens.css";

// Then anywhere:
import { Button, Input } from "@personal/design-system";
```
